# 🚀 NASA Cosmos Dashboard

A Python terminal project that:
- Tracks live astronauts in space
- Fetches NASA's Astronomy Picture of the Day
- Simulates space travel with custom packing lists

## Features
- External RESTful API Integration
- JSON Payload Parsing & Validation
- Algorithmic Conditional Logic

## Setup
```bash
pip install -r requirements.txt
python main.py
